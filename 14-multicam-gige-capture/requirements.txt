# 농산물 영상 수집 프로그램 실행에 필요한 pip 패키지.
# 설치:  pip install -r requirements.txt
#
# [주의] OpenCV(cv2)는 일부러 이 파일에서 뺐다.
#   - 이 프로젝트는 cv2.VideoWriter 를 GStreamer 백엔드(cv2.CAP_GSTREAMER)로 쓰므로
#     GStreamer 지원을 켜고 소스 빌드한 OpenCV 가 필요하다.
#   - PyPI 의 opencv-python / opencv-contrib-python, apt 의 python3-opencv 는
#     GStreamer 없이 빌드되어 있어 영상 저장이 동작하지 않는다. pip 로 설치하지 말 것.
#   - 빌드된 OpenCV 확인 (GStreamer: YES 가 나와야 한다):
#       python -c "import cv2; print(cv2.getBuildInformation())" | grep -i gstreamer
#
# 테스트 환경: Jetson AGX Orin, JetPack 5.x (L4T R35.4.1), Python 3.10, OpenCV 4.8.0 (소스 빌드)

# Basler 카메라 SDK 파이썬 바인딩
pypylon==26.7

# 테스트 환경은 numpy 1.x 로 빌드했으므로 2.x 로 올리지 말 것.
numpy==1.26.4
