# Healthcare Integration Platform

FHIR R4 and PACS/DICOM integration for medical imaging workflows.

## Components

- `fhir_client.py` - FHIR R4 client (GCP Healthcare API)
- `integration_orchestrator.py` - Async workflow management  
- `domain/` - Domain-Driven Design models

## Standards

- FHIR R4 (HL7)
- DICOM  
- HIPAA compliance considerations
