# 실시간 데스크톱 전사 (Real-time Desktop Transcription)

> AI 회의 인텔리전스 제품 **Relay**(제품명 익명화)의 네이티브 데스크톱 클라이언트.
> 회의를 녹음하면서 **실시간으로** 전사한다. 핵심 난제는 *지연(latency) vs 정확도* 이고,
> 이를 **하이브리드 STT 파이프라인**으로 푼다.

## 아키텍처

```
┌──────────────────────────── Tauri (Rust) 네이티브 백엔드 ────────────────────────────┐
│                                                                                      │
│  마이크 오디오 ─┐                                                                     │
│                 ├─► [채널 분리] ─► [VAD + 노이즈 억제] ─► f32 PCM 16kHz mono ─┐        │
│  시스템 오디오 ─┘     (me vs them)      (무음/잡음 컷)                        │        │
│                                                                              ▼        │
│                                                    ┌──────────────────────────────┐   │
│                                                    │  온디바이스 CTC (Parakeet)     │   │
│                                                    │  → partial 미리보기 (즉시)     │   │
│                                                    └──────────────┬─────────────────┘   │
│                                                                   │ 발화 종료             │
│                                                                   ▼                     │
│                                                    ┌──────────────────────────────┐   │
│                                                    │  클라우드 모델 → 최종 전사     │   │
│                                                    │  + 실시간 번역                 │   │
│                                                    └──────────────────────────────┘   │
└──────────────────────────────────────────────────────────────────────────────────────┘
                     Next.js + React UI (Tauri webview) 에 partial/final 스트리밍
```

## 왜 이렇게 설계했나 (Engineering decisions)

- **하이브리드 STT** — 온디바이스 모델이 네트워크 왕복 없이 **partial 미리보기**를 즉시
  띄우고, 더 강한 클라우드 모델이 발화별 **최종 전사**를 확정한다. 보이는 텍스트가 뒤로
  덜컥 되돌아가지(flicker) 않도록 partial↔final 을 화해(reconcile)시킨다.
- **채널 분리** — 마이크와 시스템 오디오를 독립 캡처·화자분리해서, 공유 콜에서도
  "나 vs 상대"가 정확히 구분된다.
- **VAD + 노이즈 억제를 인식기 앞단에** — 무음/잡음 구간을 걸러 낭비 추론과 헛 partial 을 감소.
- **단일 바이너리 배포** — 모델과 ONNX Runtime 을 빌드 시점에 받아 앱에 번들. 테스터는
  별도 다운로드 없이 설치만 하면 된다.

## 검증

- 서버측 STT 서비스 기준 **동시 150 세션** 실시간 처리 검증 (스트레스 테스트).

## 기술 스택

**Technologies**: Rust, Tauri, Next.js / React, ONNX Runtime, Parakeet CTC, Pyannote VAD,
WebSocket (f32 PCM streaming), 오디오 DSP
